# Drill deck — 5 minutes, on a concept that is due in any track, a different cluster than today's kata.

Sharpen tracks exist for this slot: their concepts start `practiced` and come due on a schedule,
so "read this" and "fix this" keep arriving for things you already know until the evidence says
`fluent`. A learn track's already-practiced concepts feed the deck too.

| kind | shape | what it trains |
|---|---|---|
| fix this | 20–40-line snippet with one planted bug + a failing test; the learner fixes, agent silent | debugging — the skill the AI-assistance trials show slipping first |
| read this | an unfamiliar function using the due concept; explain in plain English in ≤ 3 sentences | comprehension; predicts writing ability |
| review this | a 30-line PR-shaped diff; "what would you comment?"; graded against a hidden list of 3–5 issues | the reviewer's daily job |
| which pattern? | a problem statement with the topic label hidden; name the technique, no code | pattern recognition — the skill no roadmap trains |
| solve this | an Advent-of-Code-part-1-sized puzzle; part 2 optional and never blocking | fluency from a blank file |
| reorder this | Parsons-style shuffled lines of a correct solution | light-day drill; also right for a concept still `introduced` |
| recall | two questions on concepts that are due; chat answers | retrieval practice |

Rules: hard cap 5 min · skippable · records hit/miss only · a tangent goes to `<dojo>/experiments/`
or the study queue, never into today's box · every 5th session the drill *is* the session.
Source material for fix/read/review: shapes idiomatic to the due concept's track and, once it
exists, the capstone codebase itself — including code the agent scaffolded ahead of the ladder
(`capstone.scaffolded`): "read this" first, "fix this" a week later.
