canvas diagram kit

Diagrams are authored as mermaid source and rendered to a self-contained SVG by scripts/render_diagram.mjs (which wraps agentic-mermaid): real layered layout, orthogonal edge routing, every mermaid family. The agent writes only the source. Five visual states — base / highlight / emphasis / alert / new — are mermaid classes the renderer paints, and the legend under each diagram is live: click a chip to toggle that state's nodes, and every edge touching them, on or off.

1 · Concept map

A real shape from stet's review phase. One node carries each state; no coordinates anywhere — the layout engine places them and routes around them. Try toggling unchanged off to see only what moved.

flowchart TD
  composite["composite.run"]:::emphasis
  specialist["specialists"]
  verify["agreement-verify"]:::highlight
  coordinator["coordinator"]:::alert
  rollup["all-low roll-up"]:::new
  findings["findings"]
  composite -->|fans out| specialist
  specialist -->|submits| verify
  verify -->|feeds| coordinator
  coordinator -->|rolls up| findings
  verify -->|degraded| rollup
  rollup --> findings

The five states are the kit's; unchanged / moved / grew / drift / new are this project's labels, passed in data-legend. A consumer never invents a sixth state — it maps its vocabulary onto these.

3 · A family the old kit could not draw

Canvas's own feedback loop, as a sequence diagram. Sequence, state, class, ER and gantt all render through the same one-line call — reach for whichever actually fits the thing you are explaining. No states here, so no legend.

sequenceDiagram
  actor User
  participant Page as canvas page
  participant Server as canvas_server.py
  participant Agent
  Agent->>Page: write page + bump version.json
  User->>Page: comment on a section
  Page->>Server: POST /feedback
  Server->>Server: write feedback + wake marker
  Server-->>Agent: marker appears — watch fires
  Agent->>Agent: act on the comment
  Agent->>Page: regenerate + bump version
  Page-->>User: reloads itself

The mermaid source is the source of truth — the agent writes it, reads it back, and edits it with typed mutations rather than regenerating the whole diagram. Nothing on this page fetches anything: the SVG carries no external refs.
